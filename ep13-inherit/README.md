# 主线第 13 集：只写了一行 pass，铁皮青蛙就会走了（继承）

派派在老玩具铺里做发条玩具。先画了一张图纸 `class 发条玩具`：有名字，会上发条，会走。
想再做一只青蛙，把整张图纸再抄一遍？不用：

```python
class 青蛙(发条玩具):     # 括号里写谁，就继承谁
    pass
```

一行没写，青蛙也会上发条、也会走。

## 挑战题

### 思考题（先别运行！）

```python
class 玩具:
    def 叫(self):
        return "咔"

    def 响两声(self):
        return self.叫() + self.叫()

class 青蛙(玩具):
    def 叫(self):
        return "呱"

print(青蛙().响两声())
```

会打印出什么？

### 编程挑战（很难）

`玩具清单.txt` 里是一支游行队伍的清单，每行是「种类 名字」，小车后面还多一个颜色。可清单写得不太规矩：有不认识的种类，也有少了东西的行。

打开 `挑战.py`，爸爸 `发条玩具` 已经写好了（一个字都不许改）。你要：

1. 写出 `青蛙`、`小鸟`、`小车` 三个子类，都继承 `发条玩具`
2. 读 `玩具清单.txt`，把能看懂的行造成玩具，放进游行队伍；看不懂的行跳过（程序不许崩），但要数一数
3. 让队伍里每个玩具都 `走()` 一遍，最后打印 `游行队伍 N 个，看不懂 M 行`
4. 输出要和 `期望输出.txt` 一模一样

用得上前面好几集的东西：读文件、字典、`try/except`、`class`、继承。

```
python 检查挑战.py    # 检查你写好的 挑战.py
```

检查器有两关：第一关用 `玩具清单.txt`，第二关会换一张你没见过的清单，所以别把答案写死在程序里。没通过时它会给一句提示。
