# 派派整活实验室

B 站 [驰宇w](https://space.bilibili.com/650438749) 的视频系列「派派整活实验室：用代码回答离谱问题」配套代码。

每期视频里派派做的实验，这里都有**能直接跑的完整代码**。视频里出现的每一个数字，都是这些代码真跑出来的。

变量名大多是中文的（比如 `账本`、`得分`），Python 3 完全支持。不会编程也能大概看懂在干嘛。

## 怎么跑

1. 装好 Python 3.8 以上（[python.org](https://www.python.org/downloads/) 下载，安装时勾上 "Add Python to PATH"）
2. 点右上角绿色的 **Code → Download ZIP**，解压
3. 打开终端，进到对应那一期的文件夹，按那一期 README 里写的命令运行

不用装任何第三方库。
