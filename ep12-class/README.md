# 主线第 12 集：一块版，一百条鱼（class 类与对象）

派派接了一张订单：年画《年年有余》，鲤鱼 100 张。一条一条画，每条鱼要两个变量，一百条就是两百行。
于是他刻了一块版：

```python
class 鲤鱼:                         # 刻一块版
    def __init__(self, 名字, 颜色):  # 每印一张，先做这些
        self.名字 = 名字              # self = 正在印的这一张
        self.颜色 = 颜色

小红 = 鲤鱼("小红", "红")            # 拿红墨印一张
```

## 视频里的几段代码

都在这个文件夹里，打开终端进到这里，挨个运行：

```
python 1_一条一条画.py

python 4_竞猜.py             # 改了小红，小金还是：金
```
