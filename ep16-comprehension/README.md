# 主线第 16 集：程序员的浪漫——派派用一行 Python 绣了一颗心（列表推导式）

派派在串珠子：用老办法，一个空列表、一个 for、一个 append，四行。换成**列表推导式**，一行就够了：

```python
珠子 = [x * x for x in range(1, 11)]                 # [ 要什么  for  从哪来 ]
珠子 = [x for x in range(1, 31) if x % 3 == 0]       # 后面加 if：不合格的不要
```

两层推导式就能一行一行地「绣」出二维图案：外层管哪一行，里层管这一行的每一格。

### 编程挑战（很难）：派派的绣花图纸

`图纸.txt` 是一张十字绣图纸：每行由 `#`（要绣）和 `.`（空着）组成，有的行可能比别的行短。先补齐，再打印左右翻过来的图、放大两倍的图、要绣几针空着几格、哪几行左右对称。具体的格式和规则写在 `挑战.py` 开头的注释里，输出要和 `期望输出.txt` 一模一样。

要求：写 `翻转` 和 `放大` 两个函数；整个程序至少用 3 个列表推导式和 1 个字典推导式。

用得上前面好几集的东西：函数、字典、读文件、列表推导式。

```
python 检查挑战.py    # 检查你写好的 挑战.py
```

检查器有两关：第一关用 `图纸.txt`，第二关会换一张你没见过的图纸，所以别把答案写死在程序里。它还会检查上面的要求有没有做到；没通过时会给一句提示。

答案不公布：自己想、自己试。思考题先猜，再运行验证；编程挑战用检查器验证，两关都过就是对的。做出来的来视频评论区报个到，先别贴代码，给别人留点思考的机会。
