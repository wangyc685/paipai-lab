# 主线第 14 集：汉诺塔 64 层要搬 5849 亿年（递归）

传说有一座塔，64 个金盘子套在柱子上，一次只能搬一个，大的不能压在小的上面，全部搬到另一根柱子上，世界就会毁灭。
派派搬了 5 层就晕了。然后他想到一个办法：**想搬 n 个，先把上面 n-1 个当成一整块挪开，搬最大的，再把它们搬回来**——而「挪开 n-1 个」，交给小一号的自己去做：

```python
def 搬(n, 从, 到, 借):
    if n == 1:                  # 只剩一个盘子：直接搬
        print(从, "→", 到)
        return
    搬(n - 1, 从, 借, 到)        # 先请小派派把上面 n-1 个挪开
    print(从, "→", 到)           # 自己搬最大的那个
    搬(n - 1, 借, 到, 从)        # 再请小派派把它们搬回来
```

函数里调用它自己，就是**递归**。

### 编程挑战（很难）：派派的搬家记录本

`搬家记录.txt` 里有好几份汉诺塔的搬家记录，每份之间空一行。每份第一行是层数，后面每行是一步，比如 `A C` 就是把 A 柱最上面的盘子搬到 C 柱。

一份一份检查：搬完了用了几步、最少要几步；还是哪一步出错、错在哪；还是没出错但还没搬完。具体的格式和规则写在 `挑战.py` 开头的注释里，输出要和 `期望输出.txt` 一模一样。

要求：
1. 「最少要几步」用递归函数算（不许用 `**`）
2. 出错的时候 `raise` 一个你自己写的异常类（继承 `Exception`），在外面用 `try/except` 接住

用得上前面好几集的东西：字典和列表、读文件、`try/except`、`class` 和继承、递归。

```
python 检查挑战.py    # 检查你写好的 挑战.py
```

检查器有两关：第一关用 `搬家记录.txt`，第二关会换一份你没见过的记录，所以别把答案写死在程序里。它还会检查上面两条要求有没有做到；没通过时会给一句提示。
