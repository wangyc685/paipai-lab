# 第 11 集：训练贪吃蛇AI死了1891次，它竟然学会了……

一条小 AI 蛇在 10×10 的棋盘上玩贪吃蛇。它一开始什么都不会，全靠"得分"一点点学：做对了加分，做错了扣分。

它的脑子就是一个 **Python 字典**：

```python
账本 = {}                    # AI 的脑子：一个字典
分数 = 账本[情况]             # 查一下：这种情况下，直走、左转、右转各值几分
```

每走一步，它就照着账本挑分最高的走，走完再回头改一笔账。这种学法叫**强化学习**（Q-learning）。

## 运行

```
python snake_ai.py          # 三条规则都训练一遍，打印成绩（几分钟）
python snake_ai.py 1        # 只跑规则一
python snake_ai.py 1 看     # 训练完，在终端里放一局给你看它是怎么"躺平"的
```

跑出来的数字和视频里一模一样：

| 规则 | 测试 200 局 |
|---|---|
| 规则一：活着就加分 | 平均吃 0.15 个苹果，199 局活满 1000 步（它躺平了） |
| 规则二：吃到苹果才加分 | 平均 15.68 个，最多 36 个，172 局咬到自己 |
| 规则三：再配副眼镜（能数空地） | 平均 28.42 个，最多 44 个 |

## 你来训

打开 `snake_ai.py`，找到最上面的 `算得分()` 函数，这就是 AI 的"规矩"：

```python
def 算得分(规则, 吃到苹果, 撞死了):
    if 规则 == 1:
        得分 = 1                 # 活着，每走一步给 1 分
        if 撞死了: 得分 = -10     # 撞死，扣 10 分
    ...
```

随便改，改完再跑一遍，看看你的 AI 学成了什么样。把你的规矩和结果截图发到视频评论区。
