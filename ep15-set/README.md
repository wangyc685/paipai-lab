# 主线第 15 集：集齐 100 张卡要抽几次？派派抽了 764 次（集合 set）

派派在集卡：一共 100 张，每包一张，会抽到重复的。用列表装，重复的也照样装进去；换成**集合**，重复的就放不进去了：

```python
卡册 = set()                  # 一本空卡册
卡册.add(71)
卡册.add(71)                  # 已经有的，再放也不会多
print(len(卡册))              # 1
```

集合不收重复、没有顺序。两个集合还能比一比：`&` 都有的、`-` 我有你没有、`|` 合起来。
