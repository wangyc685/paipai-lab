# 主线第 11 集：记了一整年的账，被一杯奶茶搞崩了

派派把一年的账记在 `账单.txt` 里，一共 1080 行，一行一笔：`奶茶 15`、`外卖 23`……
他写了个小程序想把一年的钱加起来，结果跑到第 233 行「奶茶 十五」就崩了。

这一集讲的是**报错**和 **`try / except`**：
- 报错从最后一行往上看；
- 程序出事会「抛出异常」，没人接，整个程序当场停掉；
- `try / except` 就是提前说好「这种错我来接」。

## 视频里的五个版本

都在这个文件夹里，打开终端进到这里，挨个运行：

```
python 1_崩了.py           # 崩在第 233 行：ValueError
python 2_try包在外面.py     # 不崩了，但只算到 3372 元（循环早就断了）
python 3_挪进循环.py        # 第 512 行空行又崩了：IndexError
python 4_两种都接.py        # 今年花了 15898 元，看不懂的有 5 行
python 5_什么都接.py        # 今年花了 0 元（打错字的报错也被瞒下了）
```

跑出来的报错和数字跟视频里一模一样。

## 挑战题

### 思考题（先别运行！）

```python
try:
    print("A")
    int("十五")
    print("B")
except ValueError:
    print("C")
print("D")
```

会打印出什么？

### 编程挑战（很难）

看不懂的 5 行里，有 4 行人一眼就能看懂：`奶茶 十五`、`外卖 23元`、`地铁 3.5`、`煎饼 加蛋 8`。

改 `挑战.py`，把这 4 行也算进去（空行照样跳过）。做对了，总数是 **15947.5**。

```
python 检查挑战.py    # 检查你改好的 挑战.py 对不对
```

做不出来没关系，答案和讲解会发在视频评论区。
